# Expense Tracker

A lightweight CLI tool in Python for keeping track of everyday spending.

## What it does

- Log new expenses
- Display entries in a clean table
- Sum up total spending
- Filter spending by category
- Remove entries by index
- Persist and reload data via `expenses.json`

## Core concepts

- Functions and modular flow
- Lists and dictionaries
- Loops (`while`, `for`) and conditionals
- Error handling with `try / except`
- File I/O and the `json` module
